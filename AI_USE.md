# AI-assisted development disclosure

OpenAI Codex assisted with implementation, debugging, tests, interface text,
scientific-method explanations, documentation, and release-readiness review.
This includes generated and edited Python code and synthetic software-test fixtures.
Team instructions directed the work; this document does not certify the origin of
the team's initial idea or claim independent human review has occurred.

The application does not call a language model. Trend estimates and annual means
are computed in Python; explanations use deterministic templates. The original POWER responses and the two user-downloaded Giovanni browser CSVs
are preserved byte-for-byte with SHA-256 checksums. POWER records retain UTC
retrieval timestamps; Giovanni records retain the acquisition date and observed
workflow rather than an invented server timestamp. Codex assisted in reviewing
Giovanni's browser timestamp conversion and implementing the documented restoration
to the acquisition calendar, Asia/Dubai. This transformation affects derived dates,
not the original files or temperature values. Metadata absent from the chart CSV
is identified as workflow evidence; no native job metadata is fabricated.
Measurements were not generated or gap-filled by AI. Synthetic test fixtures are labeled and
are not exposed as environmental measurements.

The disclosure is displayed in Methods & sources and included in exported methods
JSON and investigation briefs. CSV data should be shared with the accompanying
methods JSON. No generated images, video, audio, or NASA branding assets are bundled.

Before submission, the team must review the claims, add any other tools or assistance
used outside this documented work, and answer the official AI/SI-use field honestly.
Do not claim that all code was independently authored by humans. Do not claim a
human science review merely because automated tests pass.

The [official submission guide](https://www.spaceappschallenge.org/resources/project-submission-guide/)
(checked 15 November 2026) calls for describing code/data assistance in text and
metadata. It also has separate disclosure and branding rules for generated media
and restricts using AI/SI to originate the solution idea. Any future submission
media must be checked against those rules; this code disclosure alone does not
cover future media or establish compliance of the team's idea-development history.
